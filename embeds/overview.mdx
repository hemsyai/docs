Hemsy Embeds let shoppers open the full Hemsy visualization experience in a modal on your own storefront. Any element on the page can become a launcher.

However it's installed, an embed comes down to three knobs:

| Knob | Where it's set | What it controls |
| --- | --- | --- |
| **Embed setup** | Once per storefront (theme editor or script tag) | Your store subdomain, which elements are launchers, and page-wide defaults |
| **Launch mode** | Per launcher | What that click opens: Sandbox, product context, Bundle, Share, Flow, or Instant |
| **Final action** | Page-wide default, overridable per launcher | What the final CTA does: Shopify checkout (default) or handing items to your cart |

Everything else in these docs is payload detail or recipes for those three knobs.

## Choose your install

There are two ways to put Hemsy on a storefront. Both load the same embed script and use the same launcher attributes. The only difference is who writes the markup.

<CardGroup cols="2">
  <Card title="Shopify theme extension" icon="shopify" href="/embeds/shopify">
    For Online Store themes. Enable the app embed and add trigger blocks from
    the theme editor. No code, and Hemsy handles the cart for you.
  </Card>
  <Card title="Script tag" icon="code" href="/embeds/script">
    For editing your theme code directly, or any page where you own the

  </Card>

| How you want to install | Install path |
| --- | --- |
| From the Shopify theme editor, no code | [Theme extension](/embeds/shopify) |
| By editing your Shopify theme code | [Script tag](/embeds/script) |
| On any other page you control (e.g., You own web app) | [Script tag](/embeds/script) |
